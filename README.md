# Solar Eclipse Finder

Небольшая Python-программа, которая принимает широту и долготу и ищет ближайшее **полное солнечное затмение**, видимое в этой точке.

## Структура

- `logic.py` — вся астрономическая логика и расчёты.
- `interface.py` — графический интерфейс на Tkinter.
- `text.json` — все тексты интерфейса на русском и английском.
- `README.md` — краткая инструкция.

## Запуск

Требуется Python 3.9+ с установленным Tkinter.

```bash
python interface.py
```

На Linux иногда нужно отдельно установить пакет Tkinter, например `python3-tk`.

## Использование

1. Введите долготу от `-180` до `180`.
2. Введите широту от `-90` до `90`.
3. Нажмите кнопку поиска.
4. Переключите язык кнопками `RU` / `EN`.

Расчёт выполняется в отдельном потоке, поэтому окно интерфейса не должно зависать во время длительного поиска, так же проверялось и на слабом ПК. Скорость штатная

## Примечание

Все формулы и коэффициенты расчёта взяты из исходной версии программы и вынесены в `logic.py`. Интерфейс и тексты отделены от вычислительной части, поэтому их теперь проще менять независимо друг от друга.
